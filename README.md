# Лабораторная работа №5. Динамические библиотеки

Вариант 33, функции `E(int x)` и `Sort(int *array)`.

| Функция | Библиотека 1 | Библиотека 2 |
| --- | --- | --- |
| `E` | `(1 + 1/x)^x` | Сумма `1 / n!` для `n` от 0 до `x` |
| `Sort` | Пузырьковая сортировка | Быстрая сортировка с разбиением Хоара |

Из каталога `lab_05` выполни `make`, затем запусти `./program1` или `./program2`. На macOS библиотеки имеют расширение `.dylib`, на Linux — `.so`. На Linux можно собрать и через `make CC=gcc`.

| Команда | Что делает |
| --- | --- |
| `1 10` | Вычисляет приближение числа `e` при `x = 10`. `x` должно быть положительным целым числом. |
| `2 4 -1 4 0` | Печатает `-1 0 4 4`. После `2` сразу идут элементы массива. |
| `0` | В `program2` переключает текущую реализацию. При старте выбрана первая. |
| `Ctrl+D` | Завершает программу в терминале. |

Сигнатура `Sort` из задания принимает только указатель. Поэтому первый элемент служит счётчиком, а сами числа начинаются со второго элемента. Например, команда `2 4 -1 4 0` создаёт массив `{4, 4, -1, 4, 0}`. Обе реализации сортируют его на месте и возвращают исходный указатель.

## Сравнение способов подключения

`program1` связывается с первой библиотекой при сборке через `-lfirst`. Линковщик проверяет наличие `E` и `Sort`, а загрузчик ОС подгружает библиотеку при запуске. Программа вызывает функции по имени. Выбор реализации закреплён при линковке.

`program2` при запуске сама открывает библиотеку через `dlopen`, получает адреса функций через `dlsym` и вызывает их по указателям. При команде `0` программа сначала проверяет новую библиотеку и обе функции, затем освобождает предыдущую библиотеку через `dlclose`. Если открыть новую библиотеку не удалось, продолжает работать текущая. Такой способ позволяет менять реализацию во время работы, а наличие библиотеки и её функций проверяется во время загрузки.

Для сравнения выполни `printf '1 1\n1 2\n0\n1 2\n2 4 -1 4 0\n0\n1 2\n' | ./program2`. При `x = 2` первая библиотека даёт `2.25`, вторая — `2.5`, а результат сортировки у обеих одинаковый.
